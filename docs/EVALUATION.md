This document contains the automated evaluation results for the **Domain Copilot HR Screening** platform. The evaluation ensures compliance with `FR-3` by measuring retrieval hit-rate, groundedness, and refusal correctness against a ground-truth dataset.

|--------|-------|-------------|
| **Retrieval Hit-Rate** | **95.0%** | The percentage of valid standard questions where the Vector Search successfully returned relevant context chunks (`sources.length > 0`). |
